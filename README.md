# Reaktionsfähig mit agentischer KI

Interaktiver Leitfaden für Geschäftsleitungen etablierter Unternehmen. Ergebnis der Masterarbeit «Organisationale Reaktionsfähigkeit im Zeitalter agentischer KI», EMBA Business Engineering, Universität St.Gallen.

## Veröffentlichen mit GitHub Pages

1. `index.html` und die leere Datei `.nojekyll` in ein Repository legen, im Hauptverzeichnis oder im Ordner `docs/`.
2. Im Repository unter Settings, Pages die Quelle «Deploy from a branch» wählen, Branch `main`, Ordner `/` oder `/docs`.
3. Nach rund einer Minute ist die Seite unter `https://<konto>.github.io/<repository>/` erreichbar.

Die Seite ist eine einzelne Datei ohne externe Abhängigkeiten. Antworten der Standortbestimmung und abgehakte Massnahmen bleiben im Browser der jeweiligen Person (localStorage), es wird nichts übertragen. Der Ergebniscode (`RF1-GL-…`) ist mit der früheren Webanwendung kompatibel.

## Inhalt ändern

Alle Inhalte stehen am Anfang des Skripts in `index.html`: `HF` (Handlungsfelder), `P` (Prinzipien), `FAELLE` und `Q` (Fragen). Massgeblich bleibt die Fassung in Anhang F der Arbeit. Änderungen dort hier nachführen.
